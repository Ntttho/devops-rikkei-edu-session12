================================================================================
PROMPT 1: PHÂN TÍCH VÀ SINH TEST CASE
================================================================================

Bạn là một Senior QA Engineer chuyên về kiểm thử hệ thống ngân hàng.
Dựa trên đặc tả API đăng ký tài khoản eKYC sau:

[API Endpoint]
POST /api/v1/registrations/register

[Input Fields]
- fullName: String, bắt buộc, tối đa 100 ký tự
- phone: String, bắt buộc, 10 chữ số, bắt đầu bằng 03x/07x/08x/09x
- email: String, bắt buộc, định dạng email hợp lệ
- citizenId: String, bắt buộc, đúng 12 chữ số

[Business Rules]
- Mỗi CCCD chỉ mở 01 tài khoản (BR-01)
- Mỗi SĐT chỉ liên kết 01 tài khoản (BR-02)
- CCCD phải đúng 12 chữ số (BR-03)

Hãy sinh danh sách Test Case đầy đủ dạng bảng Markdown với cột:
| ID | Mô tả | Dữ liệu đầu vào | Kết quả mong đợi | Loại |

Yêu cầu bao gồm:
1. Positive Test Case (ít nhất 5): Dữ liệu hoàn toàn hợp lệ
2. Negative Test Case (ít nhất 15): Để trống, sai định dạng, trùng lặp
3. Boundary Test Case (ít nhất 8): Chuỗi quá dài/quá ngắn, giá trị biên

PROMPT 3: SINH MÃ UNIT TEST JUNIT 5
================================================================================

Dựa vào mã nguồn RegistrationServiceImpl và RegistrationController từ Bài 03,
hãy viết các class JUnit 5 Test (sử dụng Mockito) để kiểm thử luồng đăng ký:

1. RegistrationServiceTest:
   - test_register_success(): Test đăng ký thành công, trả về ACTIVE
   - test_register_duplicate_citizenId(): Test ném BusinessException khi CCCD trùng
   - test_register_duplicate_phone(): Test ném BusinessException khi SĐT trùng
   - test_register_savesCorrectData(): Verify data được save đúng xuống repo
   - test_register_accountNumberGenerated(): Verify số tài khoản được sinh ra

2. RegistrationControllerTest (MockMvc):
   - test_register_validRequest_returns201(): POST với dữ liệu đúng → 201 Created
   - test_register_blankFullName_returns400(): fullName rỗng → 400 Bad Request
   - test_register_invalidEmail_returns400(): Email sai định dạng → 400
   - test_register_invalidPhone_returns400(): SĐT sai định dạng → 400
   - test_register_invalidCitizenId_returns400(): CCCD không đủ 12 số → 400
   - test_register_duplicateCitizenId_returns409(): CCCD trùng → 409 Conflict

Yêu cầu:
- Sử dụng @ExtendWith(MockitoExtension.class) cho Service test
- Sử dụng @WebMvcTest cho Controller test
- Có @DisplayName tiếng Việt mô tả từng test case
- Dùng AssertJ cho assertions (assertThat, assertThatThrownBy)

Bổ sung các test case nâng cao cho RegistrationServiceImpl:
